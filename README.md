This project uses a webcam, Processing software, and an Arduino Nano to control electrical devices through a relay module based on color detection.
When the camera detects yellow, the relay turns ON; when it detects red, the relay turns OFF.
It’s a simple yet powerful demonstration of computer vision‑based automation.

Industrial Applications
This system demonstrates how color‑based vision control can be applied to industrial machinery:

Automated sorting — detect product colors and activate conveyors or actuators.

Safety signaling — trigger alarms or shutdowns when specific color markers appear.

Process monitoring — detect color changes in fluids or materials to control pumps or valves.

Robotic control — guide robots using color cues for pick‑and‑place operations.

Daily Life Applications
Smart lighting → Show a yellow card or object to turn ON your room light, red to turn it OFF.

Fan control → Use color gestures to start/stop a fan without touching switches.

Home automation → Control appliances like TV, speakers, or lamps using color cues.

Touchless switches → Helpful in kitchens or labs where hands may be wet or dirty.

Kids’ interactive toys → Toys respond to colored cards or blocks, teaching cause‑effect.

Accessibility aids → People with mobility challenges can use colored cards to control devices.

Security systems → Detect a specific color marker to trigger alarms or door locks.

Study desk automation → Show yellow to turn ON study lamp, red to turn it OFF.
